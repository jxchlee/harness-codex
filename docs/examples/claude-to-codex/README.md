# Claude To Codex Migration Example

This example shows how to translate Claude Harness concepts into Harness Codex concepts.

Use this as a pattern, not as a file-copy recipe:

- `before-claude.md` shows a Claude-style harness excerpt.
- `after-codex.md` shows the Codex-native equivalent.

The important change is runtime semantics. Claude Agent Team instructions become Codex manager-led delegation guidance, and only when the user explicitly asks for delegation or parallel agent work.
